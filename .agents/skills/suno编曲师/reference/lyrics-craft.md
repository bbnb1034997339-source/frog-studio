# 歌词工艺(用户宪法的落地细则)

> 本文件管**通用歌词工艺**(可唱性/结构/押韵/咬字)。用户**个人风格 DNA**(意象/口头禅/情绪弧线/收尾习惯等签名写法)见 `reference/personal-style.md`——两者配合用。

## 第一原则:可唱性 > 意境

写完先**念一遍**。念着拗口、奇怪、断句别扭的,再美也要改。顺序是:**念得顺 → 有韵律 → 字数能成调 → 再谈含蓄意境**。

自检清单(每首过一遍):
- [ ] 通顺流畅,念出来不拗口、不奇怪?
- [ ] 行内字数**错落**(同段不是每行一样长)?
- [ ] 段间**对仗**(Verse1 第N行 ≈ Verse2 第N行 字数)?
- [ ] 押韵到位(副歌韵脚稳,主歌可宽松但有呼应)?
- [ ] 短句为主,逻辑有顺序?
- [ ] 副歌平实、不发散、不生僻、不拗口?
- [ ] 段尾有语气词铺垫/拉升?
- [ ] 平实但有深度,含蓄有回味,不粗浅粗俗?
- [ ] 无念白;无生僻/多音字咬字雷(否则上双版本)?
- [ ] **主歌副歌字数密度有反差?**(主歌密→副歌舒展,配合编曲收放)
- [ ] **核心钩子能否一口哼完?**(3-7 个音节,重音固定,重复后只改尾部)
- [ ] **像具体的人在说话吗?**(有对象/动作/关系/场景证据,不是抽象情绪和万能金句)

## 段落动态:歌词怎么配合编曲收放

> 编曲张力/点睛乐器/情绪弧线的设计见 `reference/arrangement-dynamics.md`。这里讲**歌词本身怎么配合动态对比**——字数、句式、语气都可以制造收放感。

### 主歌(收):密集短句,信息紧

- 字数**偏密**:每行信息量大,节奏紧,像在赶着说。
- 句式**碎**:短句叠加,可以断句多,营造"贴耳低语"的紧迫感。
- 语气**平**:叙述、白描,不抒情,把情绪压住。

```
我走在街上(5)
路灯还亮着(5)
想起从前(4)
你的样子 我快忘了(8)
```

### 副歌(放):舒展拉长,让旋律呼吸

- 字数**偏疏**:每行字数可比主歌少,或拉长成舒展的句子——给旋律留空间拉长音。
- 句式**展**:长句、排比、回环,让情绪铺开。
- 语气**开**:该抒情的地方释放,段尾加语气词推上去。

```
把你的名字 喊给这座城——(10)
风又把它 还回我手心(9)
原来想念 是自己问 自己应(11)
（噢——）(2)
```

> **关键**:主歌行均 5-6 字,副歌行均 9-11 字——这个密度差会让 Suno 自然把副歌旋律拉得更舒展,配合配器全进,反差就出来了。

### Pre-Chorus(垫):过渡句,字数渐变

从主歌的密过渡到副歌的疏,字数可以**渐变**:前两行还短,后两行拉长;或者重复一个短语推上去。

### Bridge(反转):换打法

Bridge 是**歌词最该换写法**的段落:
- 可以换人称(从"我"到"你",或到"我们")。
- 可以换句式(主歌副歌都是短句?Bridge 来排比长句)。
- 可以换语气(前面平,Bridge 突然直白/激烈/破碎)。
- 字数可以**反着来**:如果副歌是大舒展,Bridge 可以缩到极简——两三个字一行,留大量空白。

```
[Bridge - just vocal and piano, sparse]
不说了(3)
算了吧(3)
风吹过(3)
就散了(3)
```

## 字数结构:错落 + 对仗

**行内错落**(避免机械感):同一段里行的字数要有长短变化。
```
反例(机械)：        正例(错落)：
我走在那条街上(7)    我走在街上(5)
我看着那盏路灯(7)    路灯还亮着(5)
我想起了从前事(7)    想起从前(4)
我忘了你的样子(7)    你的样子,我快忘了(8)
```

**段间对仗**(主歌之间一一对应):Verse2 每一行的字数 ≈ Verse1 对应行,这样能套同一段旋律。
```
Verse 1            Verse 2
行1: 5字           行1: 5字
行2: 5字           行2: 5字
行3: 4字           行3: 4字
行4: 8字           行4: 8字
```

## 押韵

- 副歌韵脚要**稳**(同韵母收尾),主歌可宽松但段内/段尾有呼应。
- 中英混唱时,韵可落在主语言上;别为押韵硬塞拗口词(违反可唱性)。

## 副歌

- 要有**记忆点和质感**,但**不发散**:围绕一个核心意象/一句话打磨。
- **平实用词**,不拗口、不生僻、不特异。含蓄留余味,而非堆砌华丽辞藻。
- 三段副歌:内容基本重复,可在第三次微调一两字或加和声/语气词推到高潮。

### 防“AI 文案感”

歌词有 AI 感通常不是因为词太工整,而是因为**谁都能唱、什么都说了、却没有发生任何事**。

- 给叙述者一个对象和当下处境;不必写全背景,但要知道在对谁说。
- 每段至少放一个动作或可验证细节,让情绪有证据。
- 一首控制 1-2 个主意象,后续让同一意象发生变化;不要每两行换一套星河/月亮/风/海/梦。
- 抽象句与具体句交替,不要连续四行“爱、自由、遗憾、命运”。
- 允许一处口语停顿、自我修正或没说完,但不要用大量省略号伪装深度。
- 排比、反问、金句各有预算;同一种修辞不要连续用满整段。
- 删除“放到任何歌都成立”的句子。若删掉一句不影响人物和故事,它多半只是填充。

推荐检查法:把歌词中的“我/你”替换成陌生人,若整首仍完全成立,说明人物关系还不够具体。

### 旋律钩子的歌词接口

旋律无法只靠歌词精确指定,但歌词可以给它一个稳定接口。核心 hook 优先:

- 3-7 个音节,一口唱完,重音位置清楚。
- 使用容易延长的开口音和韵尾,少用连续塞口辅音或拗口多音字。
- 同一 hook 每次保留相同字数、断句和主韵脚,让模型复用同一旋律。
- 采用 `A / A / A'`:原句两次,第三次只改最后 1-2 个字或尾音。
- 可以有一个短暂停顿或弱起,制造“差一点落地”的挠人感,但不要靠突然变速。

示意:

```text
别走—— 再等一等
别走—— 再等一等
别走—— 等风停了
```

完整方法和风格框写法见 `reference/melodic-hooks.md`。

### 别致 ≠ 华丽(平实里的巧思)

平实不等于平庸。"别致"是在大白话里找一个**别人想不到的角度或支点**,不是堆辞藻。强求不来,但可以试这几招:

- **具体代替抽象**:别直说"我想你/好难过",用一个**具体的物/动作/场景**去承载情绪(把名字喊给城、留着那把空椅子、改了又删的消息)。
- **反常识小转折**:让熟悉的情绪从一个陌生入口进来(如"想念是自己问自己应")——字仍平实,但有回味。
- **支点意象贯穿**:选一个意象当锚,三段副歌各做**微变奏**,而不是换新内容。
- **留一句"空"**:不把话说满,留一句给听者自己投射。
- 守住底线:仍要可唱、押韵、不拗口——别为巧思牺牲可唱性。

> 反例(直白平庸):`我好想你 / 想得睡不着 / 全世界都知道`
> 正例(平实别致):`我把你的名字 喊给这座城 / 风又把它 还回我手心 / 原来想念 是自己问 自己应`

### 留白原则(给用户空间,别替他写满)

副歌/关键句默认产出**一个"别致版" + 保留一个"平实稳妥版"**两选一,并在**可替换的细节处标出"空"**(如 `〔你的专属地名〕`、`〔一句你们的口头禅〕`),让用户填自己的私货,而不是 AI 把所有细节都定死。别致是加分项,不强求——拿不准时给平实版兜底。

## 语气词(拉升情绪)

段尾、副歌末、Bridge 后常用,放圆括号作 ad-lib 或直接入行:
- 中:`啊` `哦` `嗯` `呜` `哎` `就这样` `别说了` `算了吧`
- 英:`oh` `yeah` `na na na` `hey` `mmm`
- 用法:`(噢——)` 单独成行做衬;或行尾 `……就走吧 (oh)`。
- 默认全曲控制在 2-4 处,同一语气词不要每个段尾机械重复。让 ad-lib 回应语义或节奏空位,不要把它当“真人感装饰”。

## 中英混唱

- **直接把中英文混写进歌词框**,suno.cn 自动识别切换发音,不要在风格框说明。
- 常见用法:主歌中文叙事 + 副歌英文 hook;或行尾英文短语点缀。
- 注意可唱性:英文部分也要顺口,别中英切换处断得生硬。

## 咬字双版本(核心避坑)

Suno 对**生僻字、多音字**常咬错。**铁律:同音同调替换,只换字不换音**(替换字字义无所谓,因为只被"听见读音"、不被看见)。

**绝不用圆括号内联标注**(圆括号会被唱出)。改用两个分开的版本:

- **送唱版**(贴进 suno.cn):只放替换字,保证唱对音。
- **存档版**(给人看):保留真正要的字。

示例:
| 想唱 | Suno 易唱错 | 送唱版替换 | 存档版 |
|---|---|---|---|
| 朝阳 zhāo yáng | 唱成 cháo | 招阳 | 朝阳 |
| 哽咽 gěng yè | 唱成 yān | 哽页 | 哽咽 |
| 脉脉 mò mò | 唱成 mài | 墨墨 | 脉脉 |
| 阿房 ē páng | 唱成 ā fáng | 婀旁 | 阿房 |

输出格式建议:
```
【送唱版（贴进 suno.cn）】
……招阳升起在山那边……

【存档版（你的歌词）】
……朝阳升起在山那边……
```

> 也可在存档版用脚注列出替换对照表,方便日后回看哪几个字动过。

## 念白

**不直接写干声念白 / spoken word**。按需求选择:

1. **旋律化 Rap(最稳)**:每行有固定拍点、韵脚和 cadence,保持 2-4 个音高支点,句尾轻微落音。
2. **Talk-singing(更像说话)**:窄音域、短句、稳定 pulse,每两行留一次换气;关键词有轻微音高,不是完全平直朗读。
3. **Rhythmic chant(适合口号/内心重复)**:短句反复,由节奏和重音制造可信度。
4. **真正旁白**:真人录制后合入,不要依赖 Suno 生成自然口语。

适合送唱的写法:

```text
[Melodic Rap Verse - narrow pitch range, steady pocket]
我没想把话说满
只是走得有点慢
灯在身后 一盏一盏
你别回头 我还跟得上
```

写作规则:

- 每行约 5-12 字,一行一个主要节奏意思。
- 2-4 行形成一组,组内保持相近重音位置和韵脚。
- 用逗号、换行制造呼吸,不要用大段散文。
- 不写舞台说明式长句,不在圆括号里放旁白。
- 避免连续低声耳语、夸张气声和无伴奏干声;这些会放大假声感。

## 用户个人风格素材(可选,详见 personal-style.md)

> 用户偏好**随意自在,不被固定风格绑住**。以下是他的已有倾向,**想用就用,不用也行**——别刻意模仿,按每首歌的感觉走。

- 第一人称可"笨拙真诚",也可别的口吻。
- 想要个人感时可植入签名意象(秋千/风/光/星),不强求。
- 情绪走向自由;口语/文白/方言/排比/回环都是可选工具。
- 常见习惯:括号制作提示、洗脑 hook、Outro 渐弱呢喃——灵活取用。
- 建议守的底线(仅三条):不歇斯底里、不堆典故、不纯绝望。
