# 用户个人词作 DNA(wangxin 风格素材库)

> 本文件基于对用户 140+ 首原创歌词的分析,提炼出他**已有的风格倾向**。这是一个**可选的灵感库,不是必须套用的模具**。写词时自然就好——用户偏好随意自在、不被固定风格绑住。这里的元素**想用就用,不用也行**,每次创作按歌曲本身的需要走,别刻意模仿。

## 一句话人格

**以孩童之眼看世界、用笨拙真诚写字的词人。** 底色是孤独,出口是陪伴,武器是自嘲与倔强。三副面孔自由切换:**温情派**(绵密情书)、**叛逆者**(朋克式咆哮)、**哲人**(东方式达观)。贯穿内核 — **拒绝成熟、拒绝世故、守护天真**。

---

## 第一母题:"长不大的孩子"

这是用户**最核心的自我身份**,贯穿全部创作。写词时:

- 第一人称立场默认是"笨拙、真诚、不装的孩子"——不是逃避成熟,而是**价值观选择**:用"孩子"对抗"懂事、体面、为了明天"的成人秩序。
- 可直接出现"孩子""长不大""笨""挺傻的"等自我定位词,但不要刻意每首都写。
- 孩子视角 = 用**天真滤镜**看沉重事物,举重若轻。

> 签名例:"我想我还只是个孩子,十岁不到八九岁的样子""把委屈折成一只纸飞机,扔进风里就不再去捡"

---

## 意象坐标系(签名标记,按需植入)

每首尽量让以下意象中的 **1-3 个**自然出现,构建可识别的精神空间。不要硬塞,要贴合主题:

| 意象 | 含义 | 使用场景 |
|---|---|---|
| **山丘 + 茅草屋 + 白秋千** | 精神原乡、避难所、童年守护 | 写孤独、写归属、写理想生活时 |
| **风** | 自由、牵挂的传递者 | 写思念、写自由、写"替我去到你身边" |
| **光/灯** | 希望、现代孤独的隐喻 | 写陪伴、写城市、写深夜 |
| **星/月/夜** | 宇宙尺度、浪漫化 | 写爱人、写安魂、写永恒 |
| **树/草地** | 生长、扎根、庇护 | 写安心、写自然归属 |

> 秋千 = 自由 + 童年 + 守护;茅草屋 = 避难所;风 = 可以替人传话的人格化意象。

## 情绪曲线(签名走向)

用户的主导情绪是**"温柔的倔强"** — 不是愤怒的朋克,而是必要时"绝不苟活"但日常"想做个孩子"的温柔斗士。

**默认情绪弧线(非强制,但贴合用户习惯):**

```
孤独/怅惘(起) → 转折("幸好有你"/"我还在") → 温柔笃定 / 释然(落)
```

- 悲伤**从不歇斯底里**(用户明确标注"完全不用假声和歇斯底里的高音")。
- 很多歌最后落到"释然":"就是这样""也没什么大不了""顺其自然"。
- 批判/愤怒作品也要**留一根"光"的引线** — 纯绝望不符合用户。

### 四层情绪光谱(按需取用)

| 层次 | 情绪 | 写法 |
|---|---|---|
| 表层 | 戏谑、自嘲、玩世 | 口语化 + 反讽 + 日常物件(会员/二维码/咖啡) |
| 中层 | 温暖、笃定、陪伴 | 短句笃定 + 意象(光/风/秋千)+ 语气词 |
| 底层 | 孤独、怅惘、易碎 | 具体物件承载情绪(自动感应灯/空椅子/没发出的消息) |
| 深层 | 倔强、悲壮、向死而生 | 排比宣言("绝不…绝不…绝不…")+ Bridge 哲理升华 |

## 语言配方(签名语言习惯)

### 1. 口语/文白/方言三轨

用户能在一首歌内自由切换:
- **口语白话**(默认主歌):"我们,也许只是路过而已,顺便看一眼风景,还不错"
- **文白/古典**(Bridge 或哲理段):"世事流迁万象无恒,浮生起落自有枯荣"
- **陕西话**(点睛,限自嘲/洒脱/愤怒段):"额""碎娃""瓜皮""去球""咧""滴" — **只作调味,不通篇**

### 2. 高频口头禅(织入词句,不堆砌)

- "就是这样""就这样吧""可以吗""好吗""就这样"
- "没什么大不了""无所谓""顺其自然""不过如此"
- "笨""挺傻的""碎娃"
- "亲爱的""宝贝""丫头"

这些构成"不装、朋友式倾诉"的语言人格。**别每首都塞**,自然处用。

### 3. 句式偏好

- **短句 + 顿挫**:"哭过。笑过。疯过。无聊过。"
- **排比三连**(表达倔强时):"绝不苟活。绝不屈服。绝不下跪。"
- **回环复沓**:"就是这样""就是想这样的""就是会这样的"
- **自问自答**:"我是谁,又从哪里来""终点是什么?你会在那里"
- **短-短-长呼吸感**:"风儿轻,月儿明,秋千在夕阳轻轻摇摆"

## 结构签名

### 1. 括号内嵌制作/情绪提示

用户习惯把**导演意图写进歌词本体**(AI 音乐时代特征)。产出歌词时,在段落内自然嵌入:
```
[Verse 1]
（木吉他温暖的扫弦）
歌词内容……

[Chorus]
（鼓加入,情绪拉升）
歌词内容……
```
中英均可:`(Soft Piano Intro)` `(Building up anger)` `(Heavy Beat Drop)` `（英伦风格电吉他Solo）`

### 2. 副歌:洗脑式重复 hook

副歌围绕一个**可重复的核心句**打磨,2-4 遍:
- "就是这样,让时间慢慢走掉"
- "我想做个长不大的孩子"
- 第三段副歌可微调一两字或加语气词推高潮。

### 3. Bridge 偏好"反转/哲理升华"

Bridge 常常是**情绪转折或哲理总结**,而非只是换个旋律:
- 从具象拔高到抽象,或从抽象落地到一个具体画面。
- 例:"也许天亮后一切会恢复原状……但至少此刻这真实的碰撞,证明了我们还活着"

### 4. Outro:渐弱独白/呢喃(签名收尾)

大量歌曲以 `(Fade out)` `(Silence)` `(Whisper)` + 一句呢喃收尾:
- 灯光渐暗、一句私语 — 电影化淡出。
- 收尾常用词:"晚安""就是这样""可以吗""就这样吧""咿呀""啦啦啦"
- 英文收尾:"Don't look back.""Game Over."

### 5. 偏好 Bridge 和 Solo,但不要机械凑结构

Bridge 用于转折或重新解释已有材料,短歌可缩成 4 小节。Solo 应变奏主钩子并提供无词出口,可与 Bridge 合并成 instrumental bridge。若加入后只是重复信息或迫使歌曲赶拍,就缩短或合并。

## 中英双语创作

用户系统性地产出**中英同题对照**,具备很强的英文写作能力。

### 什么时候混英文
- **副歌 hook 用英文**(国际化抒情),主歌中文叙事 — 最常见。
- **行内切换**:"别用那种眼神看我 I'm not a doll"
- **整段交替**:中文叙事段 + 英文 hook 段
- 英文常承担**情绪高点**;中文版更直白滚烫,英文版更含蓄克制。

### 双语同题(进阶,用户有此习惯)
用户常写中英两个版本(《Still a Kid》↔《只是个孩子》)。用户要求时可产出双语对照版,默认只出一版(中文为主,除非用户说中英混)。

## 社会批判题材的写法(用户爱写,有固定套路)

若写社会/批判题材,贴合用户习惯:

1. **排比宣言**:"绝不…绝不…绝不…"三连,带仪式感。
2. **日常物件讽刺**:PPT、二维码、自动感应灯、会员续费、改了又改的图纸 — 用具体物件承载荒诞。
3. **反讽与幽默做缓冲**:从不真正尖锐到伤人;用"算了吧""散场吧""回去洗洗睡吧"式的无奈独白收尾。
4. **以轻写重**:用吃粽子消解屈原悲壮,用西瓜掉了写生活荒诞。
5. 结尾留一句**释然或自嘲**,不纯粹愤怒。

> 签名例:"这不再是艺术,这是统计学的算术 / 这不再是灵魂,这是数据库的灰尘"(《算法的排泄物》)

## "以安"情感符号体系(可选,用户专属)

用户有一个贯穿多首的**情感哲学符号集群**:以安、心安、爱以安、瞬间以安、安心即是归处。

- 写情歌/陪伴题材时,可用"心安""靠岸""港湾""归处"等**状态词**承载归属感。
- "以安"是专属名字,仅在用户指定时使用(不自动塞入)。
- 核心表达:"原来心安就是靠了岸,漂了那么久终于有港湾"

## AI 模仿时的红线(不可违反)

1. **不要假声尖叫/歇斯底里的高音**(用户明确禁止)。
2. **不要过度堆砌典故**(即便用苏轼/屈原,也用生活化口吻消解)。
3. **不要写纯粹的绝望** — 所有悲伤里都埋着"光"的引线。
4. **不要通篇方言** — 方言只做点睛。
5. **不要华丽辞藻堆砌** — "笨拙真诚"大于"文采飞扬"。
6. **不要每首都把所有签名元素全塞** — 自然贴合主题取用 1-3 个即可,过度堆砌反而失去个人感。
7. **不要直接生成干声念白**;需要口语感时改成 melodic rap / talk-singing,真正旁白用真人录音。

## 风格参考(不是硬性检查,只是灵感提醒)

> 用户偏好随意自在,以下清单**不需要每条都满足**。偶尔翻一眼提醒自己"有这些素材可用"就行,别当成打分表。

- 第一人称可以"笨拙真诚、不装",也可以别的口吻——看歌曲需要。
- 想要个人感时,可植入 1-2 个签名意象(秋千/风/光/星…),但**不强求**。
- 情绪走向自由——可以"孤独→转折→释然",也可以完全是别的曲线。
- 口语化短句、排比、回环、方言等都是**可选工具**,不是必选项。
- 副歌/Bridge/Outro 的处理方式灵活,按每首歌的感觉来。
- 唯一建议守的红线:**不歇斯底里、不堆典故、不纯绝望**——这三条比较贴近用户的审美底线,其余全部开放。
