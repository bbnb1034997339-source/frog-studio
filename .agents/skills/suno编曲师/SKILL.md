# Suno 作词与提示词

帮用户在 **suno.cn(苏诺之音)** 及同类 AI 音乐工具上,产出**英文风格框 + 带标准元标签的歌词**。本 skill 兼顾教学引导与模板复用,默认遵循用户的「创作宪法」(见下)。

## 何时用
- 用户要写歌 / 写歌词 / 做 Suno 风格提示词
- 用户要修 Suno 的咬字、跑调、AI 味、念白问题
- 用户给一个主题/情绪/场景,想一键拿到能贴进 suno.cn 的成品

## 平台前提(suno.cn,自定义模式实测 2026-06)
界面 tab:文生音乐 / 图生音乐 / 自定义模式 / 智能创作(NEW)。自定义模式各字段:
- **歌曲名称**;**模型版本**默认 **苏诺 V5.5(官方最新)**。
- **音乐风格(英文填,上限 1000)**,右上有 **风格标签** 选择器。**注意:suno.cn 没有单独的排除标签框**,要避免的风格直接在风格框描述里用否定句写(`no trap, no EDM…`),详见 `reference/style-field.md`。
- **纯音乐** 开关;**演唱人声** 独立按钮:随机 / 男声 / 女声(人声性别可用按钮设,不必只塞风格框)。
- **歌词(上限 5000)**,右上有 **生成示例** + **段落标签** 内置选择器。
- **高级设置 → 处理已有歌曲**:上传音频(10-120秒)或选已有作品;处理方式:**扩展 / 添加人声 / 添加伴奏 / cover / 添加音轨**。
- **高级设置滑杆**:**风格参考度**(Style Influence,默认50)、**怪异参考度**(Weirdness,默认50);另有 **音色角色**(Persona,复用固定嗓音跨歌保持一致)。详见 `reference/style-field.md`。
- 机制与 Suno 同源(共现机制、元标签、`类别:值`格式)。
- 中英混唱:**直接把混合语言写进歌词框**,不要在风格框里说明。
- ❓ 仍待确认:生成后是否有片段级 Replace Section(暂用 cover/扩展 兜底)。

## 核心理念:留白 > 套路

**默认档:完整歌词 + 标出可换空位。** 出**从头填好的成品**(拿了能直接跑),但在**支点意象 / 关键细节(地点、季节、专属口头禅等)**处用 `〔…〕` 标出**可替换空位**,提示用户能换成自己的私货。既是成品,也留自由口子。

- 守住**机制**(共现、风格框vs歌词框分工、去AI味)和**用户宪法**(可唱性、错落对仗、别致不发散、偏好 Bridge/Solo 等)——但结构服从歌曲长度与真实演奏逻辑,不机械凑段落。
- 用户明确说"多留白/给骨架"→ 转成只给方向+空位;说"给我完整的、别留空"→ 填满不标 `〔…〕`。
- 例子只作**灵感**不作**模具**;别把任何示范当成必须照抄的格式。
- 拿不准的创意点(副歌角度等)可**附 1-2 个备选方向**,但主体仍交付完整成品。

## 创作工作流(默认按此走,但服务于"留白")

1. **问清意图**(缺哪个补哪个,别全问):主题/情绪、流派、速度、语言(纯中/中英混)、人声(性别/音色)、用途(自听/短视频/投稿)。**可选追加**:对唱/合唱/多声部、乐团编制(完整乐队/弦乐/管乐/大编制)、氛围场景、细化情绪。
2. **定风格框(英文,描述式自然语言)**:**全部用描述性句子写,不罗列单词标签**。按维度组织(流派/情绪/配器/节奏/人声/乐团编制/制作质感),把"声音长什么样"用完整句子串起来(V4.5/V5.5 解析好)。模仿某嗓音/乐队**别写人名**,翻译成声学特征(口音/鼻音/咬字/音域/唱腔/年代/质感),用描述句表达。**克制留白**别写满流派;描述中织入 `organic, live feel, human`(去AI味)、避免 `four-on-the-floor`,可加 `laid-back/慵懒`。详见 `reference/style-field.md`。
   - **若要混搭/段落级换风格**(用户常玩,如主歌嘻哈+副歌朋克,或加雷鬼):全局框只写"公约数",流派塞进歌词段落标签,加接缝铰链。详见 `reference/genre-mashup.md`。
3. **先锁一致性,再设计钩子、结构与动态**:先写一份贯穿全曲的“不变量”:同一主唱身份与声线颗粒、舒适音域、固定 BPM/拍号、固定 groove、核心配器和制作空间。再设计一个 1-2 小节的旋律钩子:短、可哼、节奏轮廓固定,重复后只做一次小变奏,并在 Intro/Chorus/Post-Chorus/Outro 中有限复现。之后按歌曲需要搭骨架;Bridge、Solo、三段副歌是用户偏好的常用结构,但不要为了凑齐而拉长歌曲,可用 4 小节短 Bridge、主题动机式 Solo 或合并成 instrumental bridge。动态只优先改变**配器密度、和声层数、音量与演唱力度**,不要默认换主唱、换声线、升 Key、换拍号或突然加速。详见 `reference/consistency.md` + `reference/melodic-hooks.md` + `reference/meta-tags.md` + `reference/arrangement-dynamics.md`。
4. **建立表演逻辑**:给人声安排换气、音域与装饰音预算;给每件乐器明确角色、进入原因和退出位置;保持同一房间/年代/制作空间。只加入少量有边界的自然波动,不要把“真人感”理解成随机跑拍、跑音或满屏噪声。段落标签只写本段真正变化的 1-2 件事。详见 `reference/performance-realism.md`。
5. **写词遵循宪法 + 可选参考个人 DNA**(见下),写完**自检可唱性与人物可信度**:念一遍顺不顺、字数错落+段间对仗、韵脚;检查是否有具体动作/关系/说话对象,是否堆抽象情绪、通用金句和互不相干的意象。个人风格 DNA(`reference/personal-style.md`)是**可选灵感库**,用户偏好随意自在、不被固定风格绑住,别刻意模仿——想用就用,不用也行。详见 `reference/lyrics-craft.md` + `reference/personal-style.md`。
6. **咬字双版本**:有生僻字/多音字风险时,产出**送唱版**(同音同调替换,贴进 Suno)+ **存档版**(真实字,给人看)。
7. **压缩提示词并给调优建议**:先保留 5-8 个最高优先级的正向声学锚点,否定项只留 2-4 个最可能漂移的风险;不要堆满互相竞争的要求。整首跑调时才整体换 Key(±2-3半音),不要只让终副歌升 Key;同一首的后续优先用 Persona/音色角色、已有音频续写或扩展来保持主唱身份。发现后半段赶拍时,缩短歌词或拆成扩展生成,并重申固定 BPM、拍号和 groove。
8. **需要起点时**翻 `templates/` 的轻量脚手架(民谣/朋克/grunge/嘻哈/R&B/混搭)——只借风格框起点和留白骨架,**不照抄、多留白**。

## 创作宪法(用户固定偏好,除非本次明确推翻)

**流派/速度**:民谣、朋克、垃圾摇滚(grunge)、嘻哈、R&B;以中速为主,偶快,慢速少。

**歌词**
- **可唱性第一**:先保证念着顺、有韵律、字数结构利于成调,再谈意境。通顺流畅,**不拗口、不奇怪**。
- 短句;逻辑清晰有顺序;押韵等基本功到位。
- **行内字数错落**(同段别每行一样长);**段间对仗**(主歌一第N行 ≈ 主歌二第N行 字数)。
- 副歌:有质感/特色/创意但**不发散**,**平实**用词,不拗口不生僻。
- **每首优先设计一个可哼唱的核心钩子**:3-7 个音节、1-2 小节、重复 2-3 次后只改尾部;钩子歌词保持相同重音与字数,不要每次换词导致旋律漂移。
- 段尾常加**语气词**铺垫、拉升情绪。
- 整体:平实、简单,但有深度,**含蓄有回味**;忌粗浅、粗俗。
- 倾向**三段副歌、Bridge 和 Solo**,但真实结构优先:短歌或不适合的流派可缩成微型段落、合并为 instrumental bridge,不要为了完成清单硬拖长度。

**编配/风格**:配器宽泛;**厌恶单一重复舞曲鼓点**,要**错落**节奏;略偏爱**慵懒**。**爱混搭与段落级反差**(嘻哈/朋克/雷鬼等自由组合);**风格开放、少限定**,模板是起点不是牢笼,核心 5 类之外的流派也欢迎。

**编曲张力(防平淡,重点)**:
- **主副歌必须错落**——主歌收(配器简、音区低、贴耳),副歌放(层叠、拉开、和声进)。段落间要有**明确反差**,别一条线到底。
- **选一件点睛乐器**——常规编制之外,根据情绪挑一件"签名音色"(口琴/大提琴/颤音琴/萨克斯/小号/二胡…),出现在前奏/间奏/接缝处,一下被记住。
- **情绪弧线要设计**——渐进升华 / 一路淡然 / 忽收忽放 / 反高潮,先定走法再排段落。有些歌就是要平平淡淡,那也是一种选择。
- **Bridge 要有对比但不漂移**——优先撤乐器、换和声密度或换叙事视角;默认不换 BPM、拍号、主唱或核心 groove。
- **终副歌要升级但不换歌**——优先加和声、加乐器、加演唱力度,或反高潮缩到最简;默认不升 Key、不突然加速、不把沙哑声变成清亮高音。
- **真实感 > “完美”也 > “故意做坏”**——用统一空间、合理换气、乐器互动和有限动态范围建立真人感。`organic/live/human/raw` 只能辅助,不要依赖形容词;`slightly imperfect` 必须具体说明是 loose pocket、轻微擦弦或非完全齐唱,不能同时要求跑拍、跑音和噪声。
- 详见 `reference/arrangement-dynamics.md`。

**个人词作 DNA(可选灵感库,详见 `reference/personal-style.md`)**
> 用户偏好**随意自在、不被固定风格绑住**。以下是他已有的风格倾向,**想用就用,不用也行**——别刻意模仿,每次按歌曲本身的需要走。
- **常见人格**:"长不大的孩子"——笨拙真诚、不装。但也可以是别的口吻。
- **常见情绪走向**:孤独 → 转折 → 释然。但情绪曲线自由,不强制。
- **可用意象库**:山丘/茅草屋/白秋千、风、光/灯、星/月/夜。想要个人感时可植入,不强求。
- **可用语言工具**:口语白话 + 文白古典 + 陕西话点睛;口头禅"就是这样""可以吗""没什么大不了"。全是可选,别堆。
- **常见结构习惯**:括号制作提示、洗脑 hook、Bridge 反转、Outro 渐弱呢喃。灵活取用。
- **建议守的底线**(仅三条):不歇斯底里、不堆典故、不纯绝望。其余全部开放。

**Suno 硬避坑**
- **不直接生成干声旁白 / spoken word**。需要“像说话”时,优先改成有稳定节拍和 2-4 个音高支点的 melodic rap / talk-singing / rhythmic chant;真正必须是自然口语旁白时,使用真人录音作为音频素材再合入。详见 `reference/performance-realism.md`。
- 歌词/曲调/配乐都要**真人感、去 AI 味**。
- **咬字**:生僻字、多音字会唱错 → **同音同调**替换(替换字只看音不看义),输出**送唱版/存档版**双版本;**不要用圆括号内联标注**(会被当 ad-lib 唱出)。
