# 脚手架:垃圾摇滚(grunge / 90s alt-rock)

> 起点,不是模具。grunge 灵魂是动态 soft-loud——骨架给动态走向,内容自由发挥。

## 风格框(起点,描述式写法)
```
A moody 90s grunge / alt-rock track with fuzzy distorted guitar and steady live drums, built on a dynamic soft-loud structure. A mournful cello line emerges in the quiet verses, then remains faintly audible beneath the fuller chorus guitars — the tension between fragility and noise is the emotional core. The same raspy mid-range male singer stays restrained in the verses and adds intensity without changing timbre or register in the chorus. Recorded as one live band in a warm, slightly gritty room. Mid-tempo, with bass sitting just behind the drums. No glossy pop processing, no EDM, no heavy autotune.
```
> **点睛乐器**:默认大提琴(cello,安静处的脆弱感),可换颤音琴(vibraphone)/弓拉贝斯(bowed bass)。

## 动态走向
默认**忽收忽放型**(soft-loud):主歌极静(大提琴+人声)→ 副歌增加失真与鼓组 → Bridge 收回 → 终副歌恢复完整乐队,保持原速度和声线。

## 留白骨架(标注动态)
```
[Intro - clean guitar, quiet, cello enters]

[Verse 1]
[Energy: low]
〔具体画面,留白;密集短句,贴耳低语〕

[Pre-Chorus]
[Energy: low→high]
〔起势,吉他渐入〕

[Chorus]
[Energy: high]
〔一个支点意象,平实有质感;舒展放开;+语气词〕

[Verse 2]
[Energy: low]
〔与 V1 段间对仗;cello 复现〕

[Pre-Chorus]
[Chorus]

[Bridge]
[Energy: low]
〔最安静,只剩人声+大提琴;可换人称/换句式〕

[Guitar Solo]
[Energy: medium-high] ← 增加失真和力度,不加速

[Final Chorus]
[Energy: high]
〔完整乐队回归,cello 仍隐约延续主钩子,主唱不拔出舒适音域〕

[Outro]
[Energy: low]         ← 突然安静,只剩 cello 收
```

## 调参
- soft-loud 不明显:每段前钉 `[Energy: low/high]`。
- 更脏更糊:在描述里加 `lo-fi, fuzzy wall-of-sound production`。
- **换点睛乐器**:cello 换成 `a bowed bass swells ominously` 或 `a vibraphone shimmering beneath the noise`。
