# 使用说明(怎么用 + 怎么填)

这份是**给人看的**操作手册。`SKILL.md` 是给 Claude 看的规则,你不用读。

---

## 一、怎么开始(对 Claude 说什么)

一句话说清你要的歌就行,信息越全越省事:

> "写一首关于〔主题〕的歌,〔流派/或混搭〕,〔中文/中英混〕,〔男声/女声〕,感觉像〔氛围:树下/小酒馆/演唱会…〕"

**最少**只给主题也能跑(其余我按你的固定偏好补)。**可选**加:速度、想模仿的嗓音/乐队、混音定位(人声向前等)、用途(自听/短视频/投稿)。

**也可以加这些"高级"维度**(想用就说,不说就不加):
- **对唱/合唱**:男女对唱、福音式合唱、大合唱推高潮、多声部和声
- **乐团编制**:要完整乐队感?弦乐四重奏?爵士管乐组?国风民乐?电影配乐大编制?
- **细化情绪**:不要只说"难过",可以说"倔强/释怀/暧昧/破碎感/治愈"
- **氛围场景**:海边/雪夜/城市霓虹/校园夏天/告别车站/梦境迷幻

也可以只要一部分:
- "只给我风格框" / "只要歌词骨架" / "帮我把这段歌词配个风格框" / "这句副歌卡住了,给我两个方向"。

---

## 二、你会拿到什么

默认五件套:
1. **界面设置**:模型(V5.5)、人声按钮、纯音乐开关
2. **音乐风格框**(英文,可直接粘)
3. **歌曲身份卡/钩子卡**:固定主唱、音域、BPM、groove、录音空间,并说明钩子在哪里预埋、兑现和回收
4. **滑杆建议**(只排除最可能漂移的 2-4 项,避免写满否定词)
5. **歌词**:**默认给完整成品,并在支点意象/关键细节处标出可换空位 `〔…〕`**——拿了能直接跑,也能把 `〔…〕` 换成你自己的私货。
   - 想自己掌笔 → 说"多留白 / 给我骨架";想要纯成品 → 说"填满,别留空"。

## 三、具体怎么填留白骨架(核心)

骨架里 `〔…〕` = 要你填的空,方括号 `[Verse]` 这类**别动**(是给 Suno 的结构标签)。

**填的顺序(从魂到肉):**

### 第1步:定"支点意象"
先想这首歌**围绕哪一个具体的东西**转(树荫、落叶、空了一半的长椅、没发出的消息)。一个就够,它会串起整首。

### 第2步:填副歌(先填它,定调)
副歌是魂。围绕支点意象写 3-4 行:
- **平实**:大白话,不生僻不拗口
- **别致**:找个别人想不到的角度(具体+小转折),别直说情绪
- 末行留**语气词**位置(……啊 / oh)

> 例(支点=树荫):
> 直白版 → `我一个人 坐在树下 想你`
> 别致版 → `树荫往我这边 挪了挪 / 像谁还记得 我怕晒 / 我没说话 它也没问 / 就这么陪我 坐到天黑 (……啊)`

### 第3步:填主歌1(具体画面,不抒情)
4-8 行,写**此刻看见/听见/手里在做的具体小事**,让情绪从画面里渗出来,而不是喊出来。**行内字数错落**(别每行一样长)。

### 第4步:填主歌2(对仗主歌1)
同一个场景,**时间/光线变一点**。让**第N行字数≈主歌1第N行**(这样能套同一段旋律)。

### 第5步:填 Bridge(最省、最留白)
一两句就好,甚至半句留空。放一个转折,或一句对自己/对那个人说的话。

### 第6步:通读自检(念出来)
- 念着顺不顺?拗口就改
- 押韵了吗?(副歌韵要稳)
- 有没有生僻字/多音字?→ 见第五节

## 四、怎么贴进 suno.cn

1. 打开 **自定义模式**
2. **歌曲名称**:填标题
3. **模型版本**:选 苏诺 V5.5
4. **音乐风格** 框:粘我给的**英文风格框**(已包含要避免的风格,用 `no xxx` 写在末尾)
5. **演唱人声**:点 男声 / 女声(纯音乐则开"纯音乐"开关)
6. **歌词** 框:粘歌词(连同 `[Verse]` 这些标签一起)
7. **高级设置**:拉 **风格参考度 / 怪异参考度** 到我建议的值
8. 点 **创作**,等约 1 分钟,在右侧列表听

## 五、咬字翻车怎么办(双版本)

如果歌词里有**生僻字或多音字**,Suno 常唱错(如"朝"唱成 cháo、"应"唱成 yīng)。两条路:
- **首选:换成可唱的字**(意思接近、不会唱错),最干净。
- **不能换时:同音同调替换 + 双版本**——
  - 送唱版(贴进 Suno):用读音完全一样的字(如 应→映)
  - 存档版(你留着看):保留原字
  - ⚠️ 不要用圆括号在歌词里标注原字——圆括号会被当和声唱出来。

## 六、不满意怎么调(迭代)

- **千篇一律/没感觉**:先检查是否只有一个清晰主钩子、一个签名音色和一种动态逻辑;再用同一套多生成几版挑。不要第一步就把怪异参考度大幅拉高。
- **跑调**:换 Key(±2-3 半音)再生成,比改提示词有效。
- **出 AI 味**:不要只补 `organic/human`。检查主唱是否有合理换气和固定音域、鼓与贝斯是否有稳定 pocket、乐器是否会在人声间隙让位、全曲是否像同一录音空间。
- **后半段换嗓/赶拍**:保持同一 Persona,删减终副歌字数,固定 BPM/拍号/groove,取消升 Key 与 double-time;从自然小节边界用已有音频扩展。
- **太“假旧”**:删掉多余 vinyl crackle、呼吸噪声、tape wobble 和随机不齐;一首只保留 1-2 项与流派有关的受控不完美。
- **念白感**:改成 melodic rap 或窄音域 talk-singing,保留稳定鼓点、韵脚和句尾轻微落音。真正要纯旁白时,录真人声音后作为音频/独立音轨合入。
- **混搭接缝糊**:见 `reference/genre-mashup.md`(加铰链 / 钉 Energy / 多生成)。
- **某段不行**:高级设置"处理已有歌曲"用 cover / 扩展 兜底重做。
