# bb视频拆解

把参考视频拆成可核对的镜头记录，再按镜头生成尽量贴近原片的通用中文提示词。重点是剧情片与打斗片的镜头、动作、人物、场景、节奏、声音、表演和连续性。

## 核心原则

**先做可核对的观察记录，再把有依据的内容转成逐镜提示词。** 默认忠实复刻；不补写画面或音轨未提供的动作、表情、声音、镜头参数、动机或结果。镜内运镜/动作变化不等于剪辑切镜。

## 工作流程

1. 确认当前可查看的素材：完整视频、关键帧、音轨或用户描述。不能访问的部分要说清楚，不声称已检查。
2. 先通看整段，再依据可见剪辑切点划分镜头。连续的摄影机运动、景别变化或动作阶段仍属于同一镜头；边界证据不足时标“边界待核”。
3. 为观察记录标明来源：`[画面]`、`[音轨]`、`[用户描述]`或`[推断]`。时间戳精度不能高于素材支持的精度。
4. 先交付整体概览和逐镜拆解，再对相关镜头加载专门参考：
   - 所有任务读取[镜头观察与证据](references/shot-analysis.md)。
   - 打斗任务读取[打斗动作与空间连续性](references/fight-choreography.md)。
   - 仅当剧情/互动/情绪变化有作用且面部清楚可见时，读取[表情与细微表演](references/facial-performance.md)。
5. 只在未知会改变镜头边界、关键动作因果或连续性时，向用户问一个具体问题；其他未知标为“待核”，继续完成其余分析。收到用户描述后接续，不要求重复信息。
6. 忠实拆解完成后，逐镜判断是否需要[自然度补全](references/naturalness-completion.md)，并将建议单列为“自然度补全（非原片观察）”。
7. 读取[逐镜提示词写法](references/seedance-prompts.md)，为每个镜头输出一段可单独复制的通用中文提示词。未确认 Seedance 版本及相关能力前，不添加 Seedance 专属参数；需要版本适配时，先确认版本并核实其能力。

## 默认交付结构

1. **整体概览**：素材与时间信息来源、镜头数及边界依据、人物/场景、动作或叙事主线。
2. **逐镜拆解**：必填的可核对字段，以及确有帮助的按需字段；将观察与叙事解释分开。
3. **连续性要点**：只列跨镜头需要保持的人物、空间、道具和视听状态。
4. **表演分析**：仅适用于叙事上重要且面部可见的镜头；可见动作、FACS 和叙事解释分别标注。
5. **自然度补全（非原片观察）**：逐镜单列建议；无建议时写“无需补全”。
6. **逐镜生成提示词**：每镜一段，复述该镜生成所需的角色/场景锚点。

用户只要提示词时，可以压缩前面的分析，但仍须保留证据边界、镜头边界和必要连续性。此 skill 不处理电商卖点、营销钩子或转化结构，也不上传视频或提示词。
