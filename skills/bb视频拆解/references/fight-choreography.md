# 打斗动作与空间连续性

打斗拆解优先记录可见动作因果和空间关系，不追求把每一帧都解释成完整战术。先标注观察证据，再描述动作链；被遮挡或画外发生的部分标为待核。

## 必要观察

- **人物与方位**：以画面左右或固定场景锚点标记双方位置；注明镜头轴线是否可判断。镜头反打后左右变化不能直接解释为人物换位。
- **动作阶段**：按可见顺序记录准备、发起、闪避/格挡、接触、受击/失衡、恢复或脱离。缺失阶段不补齐。
- **接触与结果**：区分明确接触、擦过、被遮挡、画面外或无法判断。只有接触证据充分时才写碰撞、命中或受力结果。
- **承重与重心**：记录支撑脚、重心转移、躯干方向、落地和失衡等能看见的变化；快速动作看不清时标待核。
- **武器与手部**：记录哪只手握持、武器朝向、掉落/交接与再取得。遮挡期间不推断所有权变化。
- **镜头关系**：记录剪切、遮挡、摇移或跟拍是否让方向/动作暂时不可见。镜内机位改变不自动构成新镜头。

## 动作因果检查

逐项核对“谁发起—对方如何回应—是否接触—接触造成什么可见变化—动作如何结束”。原片若省略过程，只写观察到的前后状态，不用常识补出完整招式。声音可辅助定位碰撞，但音效不能单独证明画面中的命中对象。

## 连续性

跨镜检查人物屏幕方位、运动方向、相对距离、武器手、服饰状态、伤痕/污渍、地面位置和环境物件。仅在前后镜头能支持时标注连续或跳变；看不清则列“连续性待核”。不要为了修复原片疑似物理错误而改写观察记录。

## 打斗提示词

按可见动作顺序写身体动力链：支撑与重心 → 发力部位 → 武器/肢体轨迹 → 接触或未接触 → 受力反应 → 收势与下一动作。用方向和接触状态减少生成歧义。自然度建议另列，不得将推断写成忠实复刻事实；快速打斗通常跳过面部细节。
